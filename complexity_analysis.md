# Complexity Analysis

### Merge Sort
- Passes for 8 elements: 3 merge levels
- Best/Average/Worst: O(n log n)
- Additional space: O(n)
- Main operation: comparisons while merging

### Quick Sort
- Partitions observed for this input: 6
- Best/Average: O(n log n)
- Worst: O(n^2)
- Additional space: O(log n) average, O(n) worst
- Main operation: pivot comparisons
